Install and set up

Install Guided Review, sign in to GitHub, and choose a model.

#Quick start

npm install -g @haydenmeloche/guided-review
gr   # the first run walks you through setup, then lists PRs awaiting your review

If gr runs something else, a shell alias is shadowing it: Oh My Zsh's git plugin defines alias gr='git remote'. Use guided-review, which the package also installs, or unalias gr in your shell config.

#Requirements

  • Node 22.13 or newer (Guided Review uses the built-in node:sqlite)
  • git
  • The GitHub CLI (gh), signed in with gh auth login, or a GitHub personal access token
  • ripgrep (rg), optional; the model's search_repo tool needs it
  • A model provider, optional; see Configure a model
  • An interactive terminal; gr does not run through a pipe
  • macOS or Linux, including WSL. Native Windows is untested.

#From npm

npm install -g @haydenmeloche/guided-review

This puts gr and guided-review on your PATH.

#From source

git clone https://github.com/HaydenMeloche/guided-review.git
cd guided-review
pnpm install
pnpm build
pnpm add -g .

If pnpm's global binary directory is not on your PATH, run pnpm setup once and restart your shell.

#Configure a model

The first run walks you through setup: a color theme, a model provider, the coding agent o opens, and GitHub access. It finds what your machine already has, such as a Codex login or an ANTHROPIC_API_KEY, and tests each model before saving. Run gr config to go through it again. An Anthropic, OpenAI, or Cursor API key is the fastest choice; Codex works from your Codex CLI login with no key. With Claude, OpenAI, and Codex models, setup runs summaries and narration at low effort to keep tours quick; Q&A uses the model's default. To review without AI, choose No AI model in setup, or pass --no-agent for one review. See Configuration for every provider, compatible endpoints, Bedrock, Vertex, and GitHub tokens.

The tour is built from static analysis of the diff and the checkout. A model adds the briefing's summary, each chapter's explanation, and answers to your questions. Without one, everything else still works, and nothing leaves your machine.

#Use from Claude Code or Codex

gr install-claude-command adds a /guided-review command to Claude Code, and gr install-codex-skill adds a skill to Codex. Both preview your local changes in a new terminal window. See Use from Claude Code or Codex.
